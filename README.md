# Security Hunter AI

Assistente web original para perguntas gerais, análise simples de imagens e busca de páginas públicas.

## Como rodar no Termux

1. Entre na pasta do projeto:

```bash
cd security-hunter-ai
```

2. Inicie um servidor local:

```bash
python3 -m http.server 8000
```

3. Abra no navegador:

```text
http://localhost:8000
```

## O que ele faz

- chatbot com respostas baseadas em regras
- análise de imagem simples a partir de URL de imagem
- busca em links públicos autorizados
- painel de uso e respostas rápidas
- design responsivo para mobile

## Observação

É um projeto original e legal, sem scraping de sites protegidos ou uso de conteúdo sem autorização.
